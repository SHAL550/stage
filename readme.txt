Welcome to my project called 📊Population Visualisation System,
This is a website which will help and allow the Rwandans and also the foreigners to explore and check population across Rwanda.
It has many users:Citizens,Government agencies,Foreigners,Immigration officers and system administrators.
Its Functionality and Requirements are Dashboard & Reports which shows the barcharts of population per districts and using the actual stastics.
This website has many features which are : showing all districts in Rwanda , displaring population per district , searching bar and the map of Rwanda.
